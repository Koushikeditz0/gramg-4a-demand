📖 User Guide
G RAM-G 4A/Demand List Builder

১. Login

Username ও PIN লিখে Login করুন। Login করলে আপনার নির্ধারিত GP স্বয়ংক্রিয়ভাবে লোড হবে।

২. Village নির্বাচন

Village নির্বাচন করলে সংশ্লিষ্ট Job Card ও worker list দেখা যাবে।

৩. Worker Search

Job Card নম্বর, Village/Household নম্বর বা একাধিক নম্বর একসঙ্গে Search করা যাবে। Space, comma, semicolon বা নতুন লাইনে একাধিক নম্বর দিতে পারবেন।

৪. Worker নির্বাচন

eKYC এবং ABPS দুটোই YES থাকা worker নির্বাচন করুন। ☑️ করে Selected List-এ যোগ করুন এবং ❌ দিয়ে ভুল selection বাদ দিন।

৫. Auto Save

Worker select/remove করলে তালিকা automatically save হয়। Logout করলেও saved list মুছে যাবে না; আবার Login করলে ফিরে পাবেন।

৬. Final Preview

Final Preview-তে Job Card No, Applicant Name, eKYC, ABPS, Account No এবং IFSC যাচাই করুন। Account না থাকলে Missing Account সতর্কতা দেখাবে।

৭. Excel Download

Final list থেকে প্রয়োজনীয় worker information-সহ Excel download করুন।

৮. PDF Download

Download PDF চাপলে সরাসরি A4 PDF তৈরি হবে। একাধিক page হলে table header প্রতিটি page-এ থাকবে।

৯. Edit List

Final Preview থেকে Edit List ব্যবহার করে আবার worker যোগ বা বাদ দিতে পারবেন।

১০. Clear Selected

পুরো Selected List মুছতে Clear Selected ব্যবহার করুন। এতে saved selection-ও মুছে যাবে।

১১. গুরুত্বপূর্ণ সতর্কতা

Demand তৈরি করার আগে eKYC, ABPS এবং Bank Account/IFSC তথ্য যাচাই করুন। ভুল worker নির্বাচন করে Demand List তৈরি করবেন না।

১২. Help & Support

সমস্যা হলে প্রথমে এই User Guide দেখুন। প্রয়োজন হলে administrator/VLE-এর সঙ্গে যোগাযোগ করুন।
