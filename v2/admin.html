🏗 Works & Supervisors

Enter the GP's works and supervisors once. In the phone app the supervisor then searches and picks the Work Name + Work Code and the supervisor Name (ID) from these lists instead of typing. While a list is empty, the phone app keeps the old typing boxes.

🏗 Works (Work Name + Work Code)

One work per line: Work Name, then the Work Code (tab, comma or space between). Or choose an Excel / CSV file with the columns Work Name and Work Code. The same Work Name again updates its code.

👤 Supervisors (Name + ID)

One supervisor per line: Name, then the ID. An ID of only digits (1, 07) becomes S-<job card prefix>-01; no ID = next free number. Names in English (the PDF does not show Bangla letters well). The same ID again updates the name.

📒 MB books

Set up / change MB books · tap to open
Option 1 — enter the range, the pages are worked out
Books issued by the Block (one continuous range). Works that are Ongoing or have an MR get pages in Job Card order (village no, household no); later works take the next free pages. MR of phase N uses first page + N − 1.
Option 2 — upload an Excel (MB numbers already given by hand)
Save the range in Option 1 first. Download the template (every work of the GP in Job Card order, with today's MB No / Page From), fill MB No and Page From (first page of the work: 1, 11, 21 …), upload. It is checked first; nothing changes until you press Apply. Works left blank / not in the file get the next free pages.

📋 All IAY works

One row per work: Job Card, beneficiary, MB No, every phase's MR (No · dates · portal status · MB page) and the wagelist. MB page for phase N = first page + N − 1.

📷 Account copy photos

Supervisors take a photo of the worker's passbook / account copy in the phone app. The supervisor also writes the Account No and IFSC. Check them against the photo: ✔ Verify saves the account in the data (update the portal too), ✕ Return sends it back to the supervisor with your reason. Either way the photo is deleted at once. Photos not checked are deleted automatically after 30 days.

📋 Ask supervisors for account copies

Paste the workers whose account is not frozen (from the Wage List page or any Excel), or choose the Excel / CSV file. Each line needs the Job Card No and the name (the name picks the right person when a job card has more than one). The supervisors see them in the phone app as 📷 Account copy চাই.

🏛 New Gram Panchayat

Add the GP here before importing its data and creating supervisors. Job Card prefix = the first 13 characters of the Job Card number, e.g. WB-08-005-014.

💾 Backup

Downloads one Excel file with all workers of the GP selected below (with accounts), all lists (including past rounds) and the user list. The Workers sheet can be imported again on this page. The file contains bank account numbers: keep it safe and do not send it to anyone. Take a backup at least once a month.

Worker and account data import

Choose a CSV or Excel (.xlsx) file. One file can hold both workers and accounts (e.g. SmartDesk Master Data). Only the 9 needed columns are taken: Job Card No, Applicant No, Applicant Name, Aadhaar Seeded, Authentication Done, ABPS, eKYC, Account No, IFSC. Other columns (Caste, Gender, Age, etc.) are ignored.

➕ New user

Username: lowercase English letters, digits, _ . - (3–32 characters). Easy PINs (111111, 123456) are not allowed. Give the PIN to the supervisor yourself.

🛡 New GP Admin (K-Desk login is made automatically)

A GP Admin opens this Admin panel but sees and controls only their own GP: lists, data import, supervisors, K-Desk login. They cannot see other GPs, add a GP or make another GP Admin. Give them the username and PIN below.
The GP's K-Desk login is created automatically with it (username and PIN are filled in for you; change them if you like).
Old method: through the Supabase dashboard (to make a Super Admin, or when the Edge Function is missing)
  1. Supabase Dashboard → Authentication → Users → Add user → Create new user.
    Email: username@users.gramg.invalid (e.g. ramesh@users.gramg.invalid), Password: a PIN of at least 6 digits, Auto Confirm User ✅.
  2. On this page press Refresh list below, pick the user, enter the name and GP and press Add profile.

🗑 Delete user

This cannot be undone. The account, its login, its devices and all of this user's lists (with past submissions and K-Desk results) are deleted permanently. Workers are not deleted. To keep the lists, use Disable instead.

🔑 New PIN

After a PIN change the user is logged out of every device at once and then logs in with the new PIN.
