💾 Backup

Downloads one Excel file with all workers of the GP selected below (with accounts), all lists (including past rounds) and the user list. The Workers sheet can be imported again on this page. The file contains bank account numbers: keep it safe and do not send it to anyone. Take a backup at least once a month.

Worker and account data import

Choose a CSV or Excel (.xlsx) file. One file can hold both workers and accounts (e.g. SmartDesk Master Data). Only the 9 needed columns are taken: Job Card No, Applicant No, Applicant Name, Aadhaar Seeded, Authentication Done, ABPS, eKYC, Account No, IFSC. Other columns (Caste, Gender, Age, etc.) are ignored.

🗑 Delete user

This cannot be undone. The account, its login, its devices and all of this user's lists (with past submissions and K-Desk results) are deleted permanently. Workers are not deleted. To keep the lists, use Disable instead.

🔑 New PIN

After a PIN change the user is logged out of every device at once and then logs in with the new PIN.
